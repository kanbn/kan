  <Card title="Trello" icon="trello" href="/integrations/trello">
    Import your Trello boards, with their lists, cards, labels and checklists.
  </Card>
  <Card title="GitHub" icon="github" href="/integrations/github">
    Import GitHub Projects as boards.
  </Card>
  <Card title="Webhooks" icon="webhook" href="/integrations/webhooks">
    Send card changes to your own server, Zapier or Slack.
  </Card>
  <Card title="MCP" icon="robot" href="/mcp">
    Manage Kan from Claude, Cursor or any MCP client.
  </Card>
</CardGroup>

Trello and GitHub connect to your account, not the workspace, so you choose which workspace to import into each time. Manage them in **Settings → Integrations**. Webhooks belong to a workspace.

To build your own integration, use the [REST API](/api-reference/introduction).
